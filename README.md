# Cat Album Telegram Bot

Простой Telegram-бот на Python, который превращает чат в личный архив фоток кота.

## Что умеет бот

- принимает фото, которые ты отправляешь в Telegram;
- сохраняет их локально в папку `cat_photos/`;
- показывает, сколько фото уже сохранено;
- присылает случайную фотку из альбома;
- хранит имя кота в настройке `CAT_NAME`.

## Команды в Telegram

- `/start` — приветствие и список команд;
- `/help` — краткая инструкция;
- `/about` — информация об альбоме и папке хранения;
- `/count` — количество сохранённых фото;
- `/random_cat` — случайная сохранённая фотка кота.

## Как скачать и запустить по пунктам

### 1. Скачай проект

Если у тебя есть ссылка на GitHub-репозиторий:

```bash
git clone <ссылка-на-репозиторий>
cd <папка-проекта>
```

Если проект уже скачан архивом, просто распакуй архив и открой терминал в папке проекта.

### 2. Установи Python

Нужен Python 3.10 или новее. Проверить версию можно так:

```bash
python --version
```

На некоторых системах команда называется `python3`:

```bash
python3 --version
```

### 3. Создай виртуальное окружение

```bash
python -m venv .venv
```

Активируй его:

```bash
source .venv/bin/activate
```

Для Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

### 4. Установи зависимости

```bash
pip install -r requirements.txt
```

### 5. Создай бота в Telegram

1. Открой Telegram.
2. Найди [@BotFather](https://t.me/BotFather).
3. Напиши `/newbot`.
4. Выбери название и username бота.
5. BotFather выдаст токен вида `123456:ABC-DEF...`.

Токен никому не показывай и не выкладывай в GitHub.

### 6. Настрой переменные окружения

Скопируй пример:

```bash
cp .env.example .env
```

Открой `.env` и впиши свой токен и имя кота:

```bash
TELEGRAM_BOT_TOKEN=твой_токен_от_BotFather
CAT_NAME=Барсик
CAT_PHOTO_DIR=cat_photos
```

Файл `.env` добавлен в `.gitignore`, чтобы случайно не залить токен в репозиторий.

### 7. Запусти бота

Вариант без `.env`, прямо через терминал:

```bash
TELEGRAM_BOT_TOKEN="твой_токен" CAT_NAME="Барсик" python bot.py
```

Если хочешь запускать из `.env`, выполни:

```bash
set -a
source .env
set +a
python bot.py
```

Для Windows PowerShell можно задать переменные так:

```powershell
$env:TELEGRAM_BOT_TOKEN="твой_токен"
$env:CAT_NAME="Барсик"
python bot.py
```

### 8. Проверь в Telegram

1. Открой своего бота по username.
2. Нажми Start или отправь `/start`.
3. Отправь фото кота.
4. Проверь `/count`.
5. Отправь `/random_cat`, чтобы бот прислал случайную сохранённую фотку.

## Где лежат фотки

По умолчанию бот сохраняет фото в папку `cat_photos/` рядом с `bot.py`.

Папка `cat_photos/` не коммитится в Git, потому что это личные файлы и они могут быстро стать большими.
